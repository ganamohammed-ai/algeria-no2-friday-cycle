أدوات QGIS لإعادة إنتاج دراسة NO2

1. افتح QGIS 3.44 أو 4.2. من Plugins > Manage and Install Plugins > Install from ZIP اختر الملف QGIS_NO2_Tools.zip الموجود في جذر الحزمة، ثم فعّل NO2 Algeria Reproducibility.
2. افتح Processing > Toolbox. ستظهر مجموعة NO2 Algeria Reproducibility وفيها 48 أداة.
3. اختر 01 Reproduce the study and verify reference results.
4. حدد Python الموجود في Local_QGIS_Runtime/Scripts/python.exe داخل الحزمة. هذه البيئة جاهزة على هذا الكمبيوتر، ولا ترفعها إلى المستودع العام.
5. حدد Zenodo/processed بوصفه Processed data root، واختر مجلد نتائج جديداً خارج البيانات. اختر extended لتشغيل إعادة الإنتاج التي اجتازت الاختبار.

الأداة 02 تنشئ طبقة للمواقع الـ19 بإحداثيات EPSG:4326. هذه مواقع الدراسة والمرجعيات والمدن الإضافية، وليست نقاط تحقق ميداني.

لتثبيت بيئة جديدة على كمبيوتر آخر، استخدم الأداة 00 مع Python 3.12 مستقل يدعم SSL. لا تثبّت الحزم داخل Python الخاص بـQGIS. البيئات المرفقة محلية لهذا الكمبيوتر؛ الملفات العامة تحتوي التبعيات الدقيقة لإعادة إنشائها.

كل سكريبت تنفيذي له أداة معالجة مستقلة بوسائط QGIS. العمليات الحسابية العلمية نفسها محفوظة في خلفية Python منفصلة، دون تغيير المعادلات أو ترشيحات الدراسة. ملفات BAT القديمة استُبدلت بهذه الأدوات. ملف sites.py المشترك بقي بوصفه إعدادات، مع أداة طبقة المواقع. خطط التحليل النصية محفوظة كما هي.

سكريبتات Earth Engine الثلاثة عشر حُوّلت إلى Python وأدوات QGIS. التشغيل الافتراضي يولّد قائمة مهام فقط دون اتصال أو تنزيل. بدء التصدير يحتاج حساب Earth Engine مصادقاً عليه وCloud project يخص المستخدم، ويكتب الصادرات إلى Google Drive كما في السكريبتات الأصلية. لم تُرسل أي مهمة بعيدة أثناء الإعداد. تم اختبار بناء الرسوم البرمجية للمهام محلياً بمكتبة Earth Engine الرسمية، دون التحقق من قيم البيانات على الخادم.

ملاحظة للمقال قبل النشر: السكريبتات الأصلية لتوصيف المواقع واختيار المرجعيات تستعمل WorldCover v200 لعام 2021، لا 2020، ومتوسط صور VIIRS الشهرية 2019–2025. لم أبدّل هذه المدخلات، ووضعت التفاصيل في SOURCE_DISCREPANCIES.txt.

الدليل التفصيلي باللغة الإنجليزية في README_QGIS.md، وقائمة تحويل كل سكريبت في SCRIPT_COVERAGE.json، ونتائج الاختبار في VALIDATION_QGIS.json.
